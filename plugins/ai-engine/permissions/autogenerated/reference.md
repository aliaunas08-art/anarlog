## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-request`
- `allow-cancel-request`
- `allow-status`
- `allow-key-status`
- `allow-set-api-key`
- `allow-clear-api-key`
- `allow-set-quotas`
